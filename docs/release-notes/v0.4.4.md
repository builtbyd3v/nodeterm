**Windows is a real target now — as an unsigned beta, and that word is doing work.** The
session-host phase landed, so the whole core experience works there: agent sessions and their
hooks, managed Claude and Codex accounts, native SSH (port and agent forwarding, `ProxyCommand`,
Pageant, `ssh.exe`), live links and co-attach, the phone relay, dev tools, run configurations, the
tray with background mode, and the session reaper and memory panel. What it does **not** have is a
code-signing certificate, so Windows SmartScreen will warn on the installer, and the build cannot
update itself: it checks for new versions and shows a card that links to the download, and you run
the new installer over the old one. Your projects and settings are kept, and on 0.4.1+ your running
sessions survive the update. Signing is the next phase.

**Updates stop nagging, and Restart finally says something.** This is the part macOS users will
notice. Clicking **Restart to update** used to look like nothing had happened while macOS staged
the update underneath; now the button shows Preparing… and Restarting… and the canvas is saved
before the app quits. Automatic checks download quietly — no progress card and no "You're up to
date" flash unless you asked — a staged update is no longer re-downloaded every six hours, and a
failed background check no longer puts up an error card. When a release carries notes, the card
shows the first few lines. Errors that do reach you are plain sentences instead of `net::ERR_*`.

**The canvas and the board got a wide pass.** The ⌘M chat view puts the keyboard straight in its
composer and gives every code block a Copy button. Kanban cards carry the session's own agent
actions, and a held launch now shows on the board with a ▶ to start it. You can choose per project
which agent actions skip the confirm dialog. There are commands for the zone thirds and quarters;
⌘+middle-drag pans past a locked canvas and the lock has its own command; the tab strip and
sessions sidebar auto-scroll while you drag something across them. Sticky notes and group frames
can take a solid backing, the model & context meter can be hidden, rendered Markdown gets a font
family, a size and visible table gridlines — and a running Flutter app can switch between checkouts
without rebuilding. `nodeterm://open` links from other apps exist behind a flag that is off by
default.

**Memory and power got stricter.** Minimize nodeterm or send it to the tray and, after two minutes,
its terminals release their GPU contexts and parked emulators — then come back warm when you
return. A window merely *covered* by another app stays warm; that distinction cost a bug on macOS
and is now explicit. On Windows, session-host scrollback is capped at 10,000 lines, which was the
single biggest memory win there. Keep-awake, which holds off idle sleep while a local agent works,
now lets go below 5% battery and re-holds when you plug in, and on a Mac a `critical` thermal state
releases it too — latched until things cool down so it cannot flap. An unreadable battery level
changes nothing, so a broken reader can never switch the feature off silently.
